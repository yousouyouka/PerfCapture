数据口径说明 L1–L4

口径：实时速率为接口总量（网卡计数器差分），今日 / 本月与历史图表为物理接口的按日累计，连接视图是当前快照不计字节——这些都不是按进程的统计；按进程的用量在报告里（需开启「进程网络用量」采集项）。VPN 激活时物理与虚拟网卡各计一层流量，属正常现象。

层级 数据来源 本页展示 / 说明
L1接口总量 网卡计数器差分（Get-NetAdapterStatistics） 下行 / 上行合计、累计、今日 / 本月与历史柱状图。VPN 激活时物理与虚拟网卡各计一层，属正常现象。
L2进程归因 内核 ETW（Microsoft-Windows-Kernel-Network） 本页不展示；报告里的按进程用量来自这里，需开启「进程网络用量」采集项。
L3连接快照 Get-NetTCPConnection / Get-NetUDPEndpoint 当前连接表；只列「现在谁连着谁」，不计字节——快照算不出流量，不猜。
L4深挖明细 外部工具 pktmon / Sniffnet 本页不展示；域名、ASN、地理与 PCAP 在外部工具里查看，数据不写入本工具。
